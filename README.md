# ccGame · Plane War（飞机大战）

一个用纯几何图形绘制的竖版飞机大战小游戏，基于 **pygame-ce** 开发，同一份代码可在 **Windows / macOS / Linux 桌面**和 **安卓手机（打包成 APK）** 上运行。

项目刻意**不依赖任何外部图片、音效素材**：飞机、子弹、道具、爆炸全部由 `pygame.draw` 实时绘制，因此打包体积小、无需资源管理，也方便直接塞进 APK。

## 功能特性

- **状态机**：开始菜单 → 游戏中 → 暂停 → 结束，四个状态互斥切换，背景星空在所有状态下持续滚动。
- **双端输入**：手机用手指拖动（`FINGERDOWN` / `FINGERMOTION`），电脑用鼠标拖动或方向键 / WASD，两套输入自动互让。
- **自动开火**：无需点按开火，火力分为 1 / 2 / 3 级，斜向子弹随等级增加。
- **道具系统**：击毁敌机有 18% 概率掉落，红十字加血（上限 3）、蓝色闪电升级火力（约 12 秒后回落）。
- **敌机体系**：普通敌机 1 血 10 分；大型敌机 5 血 50 分，开火频率更高，首次 18 秒出现、之后每 15 秒一架。
- **打击反馈**：击毁敌机生成 18 颗带阻尼衰减与渐隐的爆炸粒子；玩家受击后 90 帧无敌并闪烁。
- **HUD**：实时显示分数、生命、火力等级，文字画面带缓存，避免每帧重复栅格化。
- **暂停按钮**：右上角常驻按钮，手机无需键盘即可暂停；点击与拖动分开判定，手指拖过按钮不会误触。
- **分辨率自适应**：用 `pygame.SCALED` 按 480×800 逻辑分辨率绘制，由 SDL 等比缩放到真实窗口，安卓全屏、桌面可拖拽改尺寸。
- **自适应字体**：优先尝试中文字体，找不到时回退 pygame 内置字体，不会因缺字体崩溃。

## 快速开始（本地运行）

环境要求：**Python 3.9+**（本项目在 Python 3.13.7 上验证通过）。

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 运行
python main.py
```

`requirements.txt` 只装了 `pygame-ce`（社区维护版，与 `pygame` API 完全兼容、安装更快）。如果你更习惯官方包，`pip install pygame` 也能跑。

> 关闭窗口或按 `Esc` 退出。

## 操作说明

| 场景 | 电脑 | 手机 |
| --- | --- | --- |
| 开始游戏 | 点击 / 回车 | 点屏幕 |
| 移动 | 按住鼠标拖动，或方向键 / WASD | 手指拖动 |
| 开火 | 自动 | 自动 |
| 暂停 / 继续 | 点右上角暂停按钮，或按 `P` 键；暂停后点击画面或再按 `P` 继续 | 点右上角暂停按钮暂停，再点画面任意位置继续 |
| 重新开始 | 结束界面点击 / 回车 | 结束界面点屏幕 |
| 退出 | 关闭窗口 / `Esc` | 返回键（系统处理） |

输入优先级说明：**键盘一动就接管控制**，指针跟随立即失效；手指 / 鼠标再次拖动时指针跟随重新启用。这样两套输入不会互相拉扯。

指针事件区分「点按」与「拖动」：开始、重开、暂停恢复只认点按，手指拖动经过按钮不会误触发。

## 代码架构

`main.py` 采用「实体类 + 主控类」的单文件结构，按区块编号划分：

| 区块 | 组件 | 说明 |
| --- | --- | --- |
| 2–5 | 全局常量 | 窗口尺寸、颜色、状态编号、数值平衡参数集中定义 |
| 6 | `load_font` | 按候选列表加载字体，全部失败回退内置字体 |
| 7 | `Star` | 背景星星，出屏回收，速度/亮度/大小随机形成视差层次 |
| 8 | `Bullet` | 我方与敌机共用，靠 `friendly` 决定飞行方向与颜色 |
| 9 | `PowerUp` | 加血 / 火力道具，正弦左右摆动下落 |
| 10 | `Particle` | 爆炸火花，随机初速 + 阻尼衰减 + 寿命渐隐 |
| 11 | `Enemy` | 普通 / 大型两种配置，正弦横摆，按概率开火 |
| 12 | `Player` | 键盘 + 指针双输入、开火冷却、无敌帧、火力等级 |
| 13 | `Game` | 状态机、事件处理、生成、碰撞结算、暂停按钮、绘制、主循环 |
| 14 | `main` | 程序入口 |

主循环（`Game.run`）为经典三段式：

```python
while True:
    handle_events()        # 输入
    if state == PLAYING:
        update_gameplay()  # 移动 / 生成 / 开火 / 碰撞
                           # 非游戏态只推进星空背景
    draw()                 # 绘制当前帧
    display.flip()
    clock.tick(60)
```

碰撞检测全部使用 `pygame.Rect.colliderect`，每帧结算后统一清理失效对象，列表不会无限增长。

## 可调参数

改 `main.py` 顶部的全局常量即可（区块 2–5），无需动逻辑：

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| `SCREEN_WIDTH` / `SCREEN_HEIGHT` | 480 / 800 | 窗口尺寸（竖屏） |
| `FPS` | 60 | 帧率 |
| `PLAYER_MAX_HP` | 3 | 玩家最大生命 |
| `PLAYER_SPEED` | 6 | 键盘移动速度（像素/帧） |
| `SPAWN_INTERVAL` | 45 | 普通敌机生成间隔（帧），越小越密集 |
| `POWERUP_DROP_RATE` | 0.18 | 击毁敌机掉落道具概率 |
| `INVINCIBLE_FRAMES` | 90 | 受击后无敌帧数（约 1.5 秒） |
| `BULLET_SPEED` / `ENEMY_BULLET_SPEED` | 9 / 5 | 双方子弹速度 |
| `PAUSE_BUTTON_SIZE` | 44 | 右上角暂停按钮边长（逻辑像素） |

敌机血量、分数、开火概率在 `Enemy.__init__` 内按 `big` 分支配置；开火冷却（12 帧）与火力持续时间（12 秒）在 `Player` 类内。

画面自适应由 `SCREEN_WIDTH` / `SCREEN_HEIGHT` 与 `DISPLAY_FLAGS`（`pygame.SCALED`）共同决定：改这两个尺寸就能整体换比例，窗口由 SDL 等比缩放，绘制代码不用动。

## 打包成安卓 APK

两条路，按「本机能不能装 Linux 环境」选。

### 路线一：GitHub Actions（零环境，推荐）

代码推到 GitHub 后，由云端 Linux 机器自动构建，APK 在仓库 **Actions** 页的 **Artifacts** 里下载。本机不需要 WSL、Docker、Android SDK 中的任何一样。

- 工作流文件：[`.github/workflows/build-apk.yml`](.github/workflows/build-apk.yml)
- 触发方式：向 `master` 推送改动 `main.py` / `buildozer.spec` 的提交，或在 Actions 页手动 **Run workflow**
- 操作细节与耗时说明：[BUILD_ANDROID.md 第 3 章](BUILD_ANDROID.md#3-方案-bgithub-actions)

### 路线二：本机 WSL2

先在 Windows 上装好 WSL2 + Ubuntu（`wsl --install -d Ubuntu` 若报 `已禁止(403)`，按 [WSL2_SETUP.md](WSL2_SETUP.md) 的离线流程装），然后三条命令：

```bash
cp -r /mnt/e/it-python/ccGame ~/ccGame    # 复制进 Linux 文件系统（不要在 /mnt/e 下构建）
cd ~/ccGame && buildozer -v android debug # 构建
ls -lh bin/*.apk                          # 产物
```

完整手册（环境安装、构建、装机、签名、排错）：

**👉 [BUILD_ANDROID.md](BUILD_ANDROID.md)**

两个硬前提：

1. Buildozer 只能在 Linux / macOS 上运行，Windows 必须先装 WSL2 或使用 Docker；
2. `buildozer.spec` 的 `requirements` 必须是 `pygame`（不是 `pygame-ce`），否则 p4a 会因找不到 recipe 而中断。

## 已验证状态

在 Python 3.13.7 + pygame-ce 2.5.8 环境下用 SDL dummy 驱动做过无头回归：

- `pygame.SCALED` 显示模式生效，逻辑画面恒为 480×800（桌面 `SCALED | RESIZABLE`，安卓 `SCALED | FULLSCREEN`）；
- 点按右上角暂停按钮进入暂停，且不会把按钮位置当成移动目标；拖动经过按钮不误触发；暂停时拖动不误恢复、点按才恢复；
- 触屏同时抛出的 `FINGERDOWN` 与合成鼠标事件只触发一次切换（不会一按一恢复）；
- 键盘 `P` 键与按钮共用同一套暂停逻辑；
- 开始 / 结束界面只响应「按下」，手指还按着时拖动不会误开局或误重开；
- 键盘连续 10 帧右移位移精确为 60px（满速，不被指针目标拉扯），松键后零回弹；
- 指针拖拽吸附到目标点误差 < 2px；
- 无敌期间敌机撞击既不扣血也不坠毁；无敌结束后正常扣血；
- 玩家死亡当帧立即停止结算，生命值不会跌破 0；
- 连续 1200 帧完整跑通（生成 / 开火 / 碰撞 / 粒子 / 清理），四种游戏状态绘制均无异常；
- 离屏渲染截图核对：HUD、暂停按钮、星空、普通敌机与大型敌机、玩家、双方子弹、两种道具、爆炸粒子均正确绘制。

## 已知限制与后续可做

**当前限制**

- 画面按 480×800 逻辑分辨率等比缩放，屏幕比例不同时会留黑边（不拉伸、不变形）；想满屏需要按屏幕比例扩展可绘制区域。
- 难度曲线是平的：敌机速度、刷新间隔、开火概率恒定，只有大型敌机按固定 15 秒循环出现。
- 无音效、无震动反馈、无最高分持久化。
- 全部界面文字为英文，未做中文本地化（字体已优先选择中文字体，加上中文文案即可）。

**按性价比排序的改进方向**

1. 最高分本地存档（`json` 落盘，安卓写到 `ANDROID_PRIVATE` 目录）。
2. 随分数提升难度（逐步缩短 `SPAWN_INTERVAL`、提高敌机速度与开火概率）。
3. 补音效（射击 / 爆炸 / 拾取），注意安卓端需要把音频文件纳入 `source.include_exts`。
4. 大型敌机弹幕形态与血条显示。
